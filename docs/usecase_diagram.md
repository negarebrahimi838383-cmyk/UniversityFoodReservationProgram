#  Use Case Diagram

## هدف:
نمایش تعامل کاربران مختلف با سامانه رزرو غذای دانشجویان و عملکردهای اصلی آن.

## مراحل انجام:
1. با استفاده از ابزار mermaid دیاگرام را طراحی کنید.
2. سناریوهای اصلی سیستم را مشخص کنید (مثلاً: مشاهده منو، رزرو غذا، لغو رزرو، مشاهده سفارش‌ها).
3. دیاگرام را با فرمت md خروجی بگیرید.
4. فایل را در پوشه docs قرار دهید.
5. لینک آن را در اندیس مستندات (بخش ۲) اضافه کنید.

---

## دیاگرام موارد کاربرد:

```mermaid
usecaseDiagram
  actor Student as "دانشجو"
  actor Admin as "مدیر سلف"
  actor Kitchen as "کارکنان آشپزخانه"

  Student --> (مشاهده منوی غذا)
  Student --> (رزرو غذا)
  Student --> (لغو رزرو)
  Student --> (پرداخت آنلاین)
  Student --> (مشاهده تاریخچه رزرو)

  Admin --> (افزودن/ویرایش منوی غذا)
  Admin --> (مدیریت ظرفیت)
  Admin --> (مشاهده گزارش‌ها)

  Kitchen --> (مشاهده سفارش‌ها)
  Kitchen --> (بروزرسانی وضعیت سفارش)
```

---

## مثال ساده از موارد کاربرد:

| Use Case | Actor | توضیح |
|---------|--------|--------|
| مشاهده منوی غذا | دانشجو | دیدن منوی روز و هفته |
| رزرو غذا | دانشجو | انتخاب و رزرو غذا |
| لغو رزرو | دانشجو | لغو رزرو قبل از زمان مقرر |
| افزودن منو | مدیر سلف | اضافه‌کردن یا ویرایش غذا |
| مشاهده سفارش‌ها | کارکنان آشپزخانه | مشاهده سفارش‌های ثبت‌شده |
