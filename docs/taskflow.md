# Task Flow – جریان کار سامانه

## جریان کار برای دانشجو
1. ثبت‌نام / ورود
2. مشاهده منوی روز/هفته
3. انتخاب غذا
4. ثبت رزرو
5. مشاهده تأییدیه رزرو
6. دریافت غذا در زمان تحویل

## جریان کار برای مدیر
1. ورود مدیر
2. ثبت/ویرایش منو
3. مشاهده‌ ظرفیت‌ها و گزارش‌ها

## جریان کار برای کارکنان آشپزخانه
1. مشاهده سفارش‌های روز
2. آماده‌سازی غذا
3. تغییر وضعیت سفارش (در حال آماده‌سازی → آماده → تحویل داده شده)
