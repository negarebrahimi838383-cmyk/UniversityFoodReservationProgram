# طراحی سیستم

## معماری کلی سیستم
سیستم از سه لایه اصلی تشکیل شده است:

### 1. لایه ارائه (Presentation Layer)
- شامل رابط کاربری وب برای دانشجویان، مدیر سلف و ادمین سیستم  
- تکنولوژی‌های پیشنهادی: **HTML**, **CSS**, **Bootstrap**  
- در صورت نیاز به نسخه پویا و SPA، استفاده از **React** یا **Vue.js** نیز مناسب است

### 2. لایه منطق کسب‌وکار (Business Logic Layer)
- پیاده‌سازی منطق‌های اصلی سیستم شامل رزرو، مدیریت کاربران، نمایش منو و پرداخت  
- فریم‌ورک‌های پیشنهادی:
  - **Django** (پایتون)
  - **Laravel** (PHP)
- این لایه قوانین مربوط به ظرفیت غذا، محدودیت زمانی لغو رزرو و کنترل نقش‌ها را مدیریت می‌کند.

### 3. لایه داده (Data Layer)
- مدیریت ذخیره‌سازی داده‌ها و ارتباط با پایگاه داده  
- پایگاه داده پیشنهادی:
  - **MySQL**
  - **SQLite** (برای نسخه‌های سبک یا توسعه اولیه)

## طراحی پایگاه داده (به صورت توضیحی)

### جدول Users
- نگهداری اطلاعات کاربران  
- فیلدهای اصلی:
  - student_id (کد دانشجویی)
  - name
  - password (هش‌شده)
  - role (Student / Manager / Admin)

### جدول Meals
- اطلاعات وعده‌های غذایی  
- فیلدها:
  - meal_id
  - name
  - date
  - price
  - capacity

### جدول Reservations
- ثبت رزروهای انجام‌شده  
- فیلدها:
  - reservation_id
  - user_id
  - meal_id
  - reservation_date
  - status

### جدول Payments
- ثبت اطلاعات پرداخت‌ها  
- فیلدها:
  - payment_id
  - reservation_id
  - amount
  - payment_status

## طراحی امنیت سیستم

- **رمزنگاری رمز عبور** با الگوریتم مناسب (مانند SHA-256 یا bcrypt)  
- **کنترل سطح دسترسی** بر اساس نقش‌های مختلف کاربران  
- **استفاده از نشست (Session) امن** برای مدیریت ورود کاربران  
- جلوگیری از حملات رایج مانند:
  - SQL Injection  
  - XSS  
  - CSRF
